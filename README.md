# nmos-reference

Python reference implementation of an NMOS Node with Matrox NMOS extensions.

It aims to provide a typed, testable, and open-source-friendly implementation of the supported NMOS APIs and Matrox extensions.

## Compliance Boundary

This repository must not be described as "fully compliant with everything under `specs/`".

The `specs/` directory is the broader Matrox documentation corpus. The Python implementation intentionally supports only part of that corpus today.
